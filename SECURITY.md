# Security policy

## Reporting a vulnerability

Please do not open a public issue. Report it privately through GitHub's
"Report a vulnerability" button (Security tab) of this repository. You will get
an answer within a few days.

## Scope

This library handles bunny.net API keys and signs URLs. Reports about key
leakage in logs or errors, weak signing, or request smuggling are especially
welcome. Only the latest minor release receives fixes.
